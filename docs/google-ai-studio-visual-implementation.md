# 《孤山独影》Google AI Studio 视觉匹配需求表

请在视觉任务分支实施，使用 Pull Request 交付。改动集中在 `visual/`，读取 `shared/` 现有状态。沿用现有输入、抓点、重心、IK、物理、碰撞、体力和关卡规则。如必须修改 `shared/` 或 `app/`，先列出字段或接入点、文件、原因和影响，等确认。

| 阶段 | 代码要求 | 验收 |
|---|---|---|
| 起步 | 对应材质的起步底图铺满竖屏，按原起始位置渲染角色。底部岩台与实际脚底对齐。 | 无悬空或陷入，攀爬开始时岩纹比例连续。 |
| 攀爬 | 复用同材质近景岩壁，按纵向接续适配不同高度。岩面超出视口两侧。人物、岩点、反馈分别绘制并共用世界坐标变换。 | 短线与高线无露底、侧缘和明显横缝。相同输入得到相同结果。 |
| 岩点 | 每种材质十款透明 PNG，按既有外观变体或稳定 ID 选图。仅围绕既有接触锚点旋转缩放贴图。 | 手脚、可见抓边和实际命中位置一致。冰岩与花岗岩的同编号可互换。 |
| 读线 | 淡出岩壁、山形、场景和人物，只留原位岩点与必要提示。保留进入时镜头位置和缩放；已有读线拖动时退出恢复原位。 | 切换无岩点跳位，退出可立即继续攀爬。 |
| 登顶近景 | 接近末端时逐步露出顶沿和天空，沿用既有登顶事件。角色站稳后短暂停留。 | 最后一抓可操作，登顶结算一次。 |
| 广角结尾 | 短暂退远并叠化至静态全山插画，预先加载图片。雪脊用 V 形缺口和右侧雪檐匹配；霜冠用鞍形山脊和斜向蓝冰带匹配。随后进入原结算。 | 无空白帧或闪屏，近景与广角可认出同座山，重开及返回正确复位。 |
| 手机交互与性能 | 装饰层不拦截触控。缓存解码后的纹理，避免逐帧创建大图。 | 在 390 × 844 竖屏检查抓点、读线、重开和返回。记录素材加载、爬升和切图的实际表现。 |

## 素材映射

两套素材为雪脊花岗岩和霜冠冰岩。每套包含起步、攀爬岩壁、登顶近景、广角结尾、十种岩点图集和十张独立透明 PNG。按材质共享起步、岩壁与岩点，按山峰配对登顶近景与广角。按实际收到的文件导入原始 PNG；ZIP 用于分发，运行时使用解包后的文件。未取得素材时在 PR 中标明，沿用现有显示。

请运行构建和相关测试，用两套材质验证上述画面并附截图或录屏。PR 列出修改文件、视觉变化、性能影响和风险，标明真机或浏览器模拟。
