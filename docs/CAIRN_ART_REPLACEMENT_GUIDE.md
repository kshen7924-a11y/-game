## 一、Cairn 目标美术风格圣经（对照参考图 1:1 锁定）

根据你提供的 Cairn 实机参考图，所有由 Codex 生成或重绘的美术资产（岩壁、岩点、道具、人物）必须严格遵循以下 **6 条视觉一致性铁律**，否则拼合后会出现割裂感：

### 1. 线稿与着色语言：法比漫画清线（*Ligne Claire* / Mathieu Bablet 风格）
- **硬边暗墨线轮廓**：所有岩壁大裂隙、岩棱折面、岩点边缘、人物外轮廓、绑带、背包带、攀岩绳与机械岩钉，统一使用**锐利、干净的深蓝黑墨线（`#141C24` / `#101720`）**，禁止使用模糊软笔刷黑边。
- **硬边二分赛璐璐阴影（Cel-Shading）**：明暗交界线必须果断、利落，**禁止使用油腻的 3D 塑料高光、高斯模糊投影或脏褐色喷枪过渡**。

### 2. 参考图实测标准色板（全项目必须统一取色）

| 视觉层级 | 主色 Hex | 辅助/斑驳色 Hex | 阴影色 Hex | 墨线色 Hex |
| :--- | :--- | :--- | :--- | :--- |
| **花岗岩/石灰岩主岩壁** | `#BCC7CB` ~ `#CFD8D6`（冷灰白岩） | `#B3C4B0` / `#C4D2BA`（淡青灰地衣苔藓斑驳） | `#395C6E` ~ `#244052`（冷青灰/普鲁士蓝岩缝阴影） | `#141C24` |

### 3. 统一光照方向与投影规则
- **主光源**：**左上方约 45° 自然晴空冷日光**。
- **受光面**：偏冷白/微暖灰白；**背光面与裂缝深处**：冷青蓝（`#2A4A5E`），绝不用纯黑或脏棕。
- **引擎已内置同步投影**：引擎渲染层已在人物与攀岩绳背后自动投射**硬边冷青灰岩壁投影**（`CAIRN_REFERENCE_ATMOSPHERE_GRADE.castShadowColor`），随贴壁距离 `wallHug` 动态缩放，Codex 切图时**人物各部件与绳索不要自带大面积背景投影**，只需画自身结构明暗！

### 4. 去游戏化 UI 原则（Diegetic Minimalism）
- 在 `ArtPackUrls.atmosphereGrade` 中开启 `CAIRN_REFERENCE_ATMOSPHERE_GRADE`（含 `diegeticMinimalCues: true`）后，引擎会自动压低发光霓虹圈，切换为细腻的漫画虚线/粉笔提示，保证画面像参考图一样纯粹干净。

## 二、引擎已提前预留的全部 Cairn 美术替换槽位总表

所有接口已统一汇总于 **`src/visual/artRegistry.ts`**。Codex 只需生成对应透明 PNG/WebP，放入规定目录，并在注册表中绑定即可生效。

### 模块 A：岩壁、地形大板与氛围调色（`ART_PACK_MANIFEST` / `registerArtPack`）

引擎已预留全部 **4 套地形主题包**（覆盖全部 11 条线路的 `granite` / `ridge` / `slate` / `glacial`）：
- `snow-ridge-granite`（明亮冷灰石灰岩/花岗岩 — **最贴合参考图主风格**）
- `ridge-alpine`（高山刃脊 + 青苔风化岩壁）
- `slate-cliff`（深青灰层理板岩绝壁）
- `frost-crown-ice`（高寒霜冠冰岩壁）

每套包可替换资源清单：

| 槽位字段 | 建议文件名 | 尺寸与格式 | Cairn 风格绘制规范 |
| :--- | :--- | :--- | :--- |
| `start` | `01-起点.png` | `1080×1920`（9:16 RGB） | 顶部 `0%–18%` 为纯岩壁无缝过渡区；起攀岩台表面在纵向 `85.5%` 处 |
| `wall` | `02-攀爬岩壁.png` | `1080×1920`（9:16 RGB） | 垂直无缝循环（底部 `16%` 自动叠融至顶部）：冷灰岩面 + 地衣斑驳 + 硬边墨线节理裂隙 + 冷青阴影面，切忌画面中间出现突兀孤立物体 |
| `wallDetailOverlay` | `02b-笔触线稿层.png`（可选） | `1080×1920`（RGBA 透明） | 稀疏法比漫画手绘墨线短排线与微颗粒纹理，以 `0.22` 透明度叠在岩壁上增强手绘感 |

### 模块 B：岩点与材质状态叠加层（`holds` + `holdOverlays` + `specialHolds`）

1. **10 张基础岩点（`holds[0..9]`，`512×512` 1:1 RGBA 透明 PNG）**
   - 形态编号严格保持 `01-厚弧岩沿` ~ `10-斜向裂缝`，锚点 `(anchorX, anchorY)` 已与物理抓握点 1:1 校准。
   - **Cairn 岩点绘制关键**：**不要画成圆滚滚的室内攀岩彩点！**必须画成从岩壁自然裂出、带有锐利墨线边缘与冷青底影的**原生天然岩棱、岩阶、岩缝与凹窝**，让岩点与岩壁浑然一体但靠折面与暗缝清晰可读。
2. **5 张材质状态透明叠加层（`holdOverlays`，`256×256` RGBA，居中锚点）**
   - `chalk`（`overlay-chalk.png`）：干涩哑光白色镁粉指印抹痕
   - `wet`（`overlay-wet.png`）：雨淋深青湿岩块面 + 细锐白色水膜反光线
   - `crack1` / `crack2` / `crack3`（`overlay-crack-1~3.png`）：脆岩 3 阶段硬墨线龟裂纹与剥落碎石碴
3. **4 张特殊动态岩点覆写（`specialHolds`，可选，`512×512` RGBA）**
   - `spring`（借力蹬踏岩阶）、`swing`（摆荡圆弧握沿）、`tremor`（松动微裂岩块）、`decoy`（低对比平滑假点/干扰岩凸）

## 三、给 Codex 的直接执行指令模板（复制即用）

```text

1. 严格使用硬边深蓝黑墨线（#141C24）+ 硬边冷青灰二分阴影（#395C6E / #244052）+ 左上 45° 自然冷光，禁止 3D 塑料感、软喷枪糊边与霓虹发光。

- 所有尺寸、锚点与目录严格遵循 `docs/CAIRN_ART_REPLACEMENT_GUIDE.md`。
```
