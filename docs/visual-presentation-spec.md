# 《孤山独影》视觉展示实施规范

供 Google AI Studio 和 Codex 作为视觉任务的实施依据。画面顺序为起步、攀爬、登顶近景、广角定格。读线是攀爬中的临时视图。

## 协作边界

- 开工前检查当前分支的目录和现有状态接口，以仓库实际结构为准。通过 visual 任务分支和 Pull Request 交付。
- 在 `visual/` 实现素材配置、人物绘制、岩壁、岩点外观、UI、动画和特效。读取 `shared/` 已约定的游戏状态，沿用角色姿态、手脚接触、岩点坐标、输入命中和登顶结果。
- `gameplay/` 的物理、IK、碰撞、体力、关卡规则和操作结果由玩法系统负责。视觉层不得另行计算抓点、重心或胜负。
- 如需改动 `shared/` 或 `app/`，先列出变更内容、受影响文件、原因和兼容影响，等待确认。可独立完成的视觉工作继续进行。

## 画面与验收

| 阶段 | 实施要求 | 验收 |
| --- | --- | --- |
| 起步 | 显示起步底图，游戏角色站在底部岩台。沿用现有起始坐标。镜头上移时衔接同材质的攀爬岩壁。 | 脚底贴合岩台，起步与攀爬之间岩纹尺度和色温连续。 |
| 攀爬 | 岩壁铺满竖屏并延伸出视口两侧。纵向接续岩面适配不同高度，保持纹理尺度。角色和岩点实时分层绘制。 | 短线、高线均无露底、山体侧边或明显横缝。 |
| 岩点与角色 | 每种材质使用十种透明岩点。使用现有外观变体，或按岩点 ID 稳定选图。围绕实际接触点旋转和适度缩放。读取现有姿态、接触、选中、可达和教学状态。 | 岩点外观稳定，手脚贴合可见抓边，命中和玩法结果一致。 |
| 读线 | 岩壁、场景、山峰轮廓和角色淡出，只留原位岩点与必要提示。保持坐标变换。如果已有读线拖动，退出时恢复进入前的镜头。 | 同一岩点切入时不跳位，退出后回到可继续操作的位置。 |
| 登顶近景 | 接近顶峰时露出顶沿和天空。现有登顶事件触发近景，角色站稳后短暂停留。 | 最后一抓仍可操作，角色越过顶沿，登顶只结算一次。 |
| 广角结尾 | 轻微退远并叠化到对应山峰的静态全山插画。用近景和广角共有的峰脊、缺口、雪檐或冰带对齐。随后进入原有结算流程。 | 无空白帧或闪屏，能认出同一座山，重开或返回时清理上一局过渡。 |
| 手机 UI | 沿用现有入口与触摸区域，装饰及过渡层避免拦截输入。复用已加载纹理，在登顶过渡前准备好广角图。 | 手机竖屏下抓点、读线、暂停、重开、返回可用。 |

## 素材清单与映射

起步图、攀爬岩壁和岩点按材质共享。登顶近景和广角插画按山峰成对配置。每套有四张无人竖屏场景、一张岩点图集及十张独立透明 PNG。角色由游戏渲染。岩壁源图的纵向循环接缝需要在接入时验证。

| 素材包 | 结尾对齐特征 |
| --- | --- |
| 雪脊花岗岩 | 左侧 V 形缺口和右侧雪檐 |
| 霜冠冰岩 | 左低右高的鞍形山脊、右侧厚冰檐及斜向蓝冰带 |

十种岩点在两套中顺序一致。依次为厚弧岩沿、薄片小边、三角捏点、圆头岩角、低弧斜面、倒扣薄缘、双层阶块、竖向侧拉、月牙凹窝和斜向裂缝。本次文档记录素材约定，原始 PNG 和 ZIP 由项目方另行提供。

## PR 验证

- 两套材质各验证起步、攀爬、读线、登顶近景、广角结尾，附截图或短录屏，并标注真机或浏览器模拟。
- 对照相同路线和相同输入，验证抓点命中、手脚接触、体力变化及登顶结果。运行仓库构建和相关测试，记录实际命令及结果。
- PR 列出修改文件、视觉变化、性能影响及风险。核对首屏加载、爬升滚动和登顶切图。区分实测与预期。
